# Regression fixture for the classifier, the region map and the suppression gates.
#
# THIS FILE IS THE RECORD OF CHRIS'S MARKUP. Every correction he makes on a briefing goes in
# here as a case BEFORE any pattern is edited: write the case, watch it fail, then fix the
# rule until it passes. Done in that order the reasoning is preserved as an executable claim
# rather than as a comment next to a regex, and the correction can never silently regress.
#
# Run:  python3 run_tests.py
#
# Format, one assertion per line, fields separated by |
#   SECTION <name>   | <outlet> | <headline>
#   REGION  <tier>   | <outlet> | <url or -> | <headline>
#   SUPPRESS         | <outlet> | <headline>      (chaff / school gates / local incident)
#   KEEP             | <outlet> | <headline>      (must NOT be suppressed)
#   OUTLET  <shown>  | <raw outlet name>          (tidy_outlet, incl. paywall renames)
#   ABOVE            | <headline A> | <headline B>  (A must outrank B in importance())
#
# ABOVE is the RANKING record - the ground truth the other kinds are for classification.
# Every time Chris says a story ran too low or too high, that judgement becomes an ABOVE
# pair here, failing first, before any scoring pattern is touched. This is what makes a
# scoring change measurable: without it every importance() edit is justified by one
# anecdote and silently free to regress the last one. Pairs are scored on headline
# vocabulary alone (no corroboration), so use them for the said-versus-happened, scale
# and commentary axes - not for "this was a bigger story that day".
# Lines starting with # are comments. Keep the date and the reason on the comment above a
# block - a future reader needs to know whose judgement a case encodes.

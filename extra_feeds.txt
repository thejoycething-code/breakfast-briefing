# Additional / corrected feeds for the Breakfast Briefing sweep.
# Format:  mode | category | outlet name | url
#   mode = pass       -> every item kept (issue-specific source)
#          filter     -> only items matching the topical keyword list
#          gnews      -> Google News site: search (feedless outlet), keep all
#          gnewsf     -> same, but keyword-filtered (for broad general outlets)
#          bing       -> Bing News site: search; unlike Google these give DIRECT
#                        publisher links, but coverage is thin (~14 items)
#          bingf      -> same, keyword-filtered
#          scrapesrc  -> read an index page as a source (outlet has no feed at all);
#                        no dates, so a link absent from seen.json counts as new
#          scrapesrcf -> same, keyword-filtered
#          scrape     -> index page read ONLY to resolve gnews links to direct URLs
#          disable    -> never fetch this url fragment (dead/stale feed)
#          block      -> drop any item from this outlet/domain (aggregators, junk)
# An optional 5th field sets a longer sweep window for that source alone:
#     pass | category | outlet | url | window=168h
# Use it for sources that publish a few times a WEEK - the default 36h window misses them
# most days, and a silent miss is indistinguishable from a quiet news week. Never shortens
# the window, only lengthens it, and must stay under SEEN_RETENTION_DAYS (21d) so a story
# already published is not offered again. run_tests.py asserts that.
# Lines starting with # are ignored. Edit freely; the sweep picks changes up
# on the next run.
